# Адаптация Promptriever для русского языка

Курсовая работа по адаптации методологии [Promptriever](https://arxiv.org/abs/2409.11136)
на русский язык: bi-encoder ретривер, который умеет учитывать инструкции в запросе.

## Идея

Базовый bi-encoder (multilingual-e5-base / bge-m3 / Qwen3-1.7B) дообучается на
русскоязычной части [mMARCO](https://huggingface.co/datasets/unicamp-dl/mmarco)
с синтетически сгенерированными инструкциями и instruction negatives — документами,
которые релевантны запросу по теме, но не удовлетворяют условию инструкции.

Гипотеза: после такого дообучения модель начинает реагировать на формулировку инструкции, а на стандартных IR-метриках не проседает.

## Структура

```
notebooks/
  data_prepare.ipynb - сборка датасета
  train.ipynb - обучение и оценка экспериментов
prompts/ - промты, которые использовались при сборке датасета
data/
  golden_set — голденсет (82 примера после фильтрации)
  train — финальный обучающий датасет
```
